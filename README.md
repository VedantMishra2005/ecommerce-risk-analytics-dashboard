# Project Overview

This project transforms raw e-commerce order data into a modern interactive business intelligence dashboard.

The dashboard helps analyze:
- Fraud patterns
- Return risks
- Customer behavior
- Revenue trends
- AI-inspired risk scoring
- Business KPIs

The project was built using SQL, HTML, CSS, JavaScript, and Chart.js with AI-assisted dashboard development.

# Dataset Information

The dataset contains 12,000+ e-commerce orders from 2023–2025 including:
- Revenue
- Fraud Labels
- Return Status
- Payment Methods
- Device Types
- Customer Reviews
- Traffic Sources
- Country Information
- Risk Indicators

---

# Key Business Insights

- Gift Card payments showed the highest fraud rate.
- Fashion products generated the highest return percentage.
- Paid Ads traffic contributed significantly to fraud activity.
- Desktop users had slightly higher average order values.
- Low review scores strongly correlated with product returns.
